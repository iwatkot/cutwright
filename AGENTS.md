# CutWright contributor instructions

For any editor change, read and apply `.agents/skills/cutwright-user-docs/SKILL.md`. Every change requires a documentation review and corresponding update. New features or changed behavior must update the detailed user manual in the separate `cutwright-website` repository before delivery. Published manuals contain only user workflows and exact steps, never implementation details. The website manual's source is `content/docs/`; see that repository's README for generation and checks.

Keep editor controls compact and contextual. Preserve canvas and timeline space; use reusable themed controls and accessible icon buttons. Do not add native select/range/number/color widgets or browser title tooltips.
